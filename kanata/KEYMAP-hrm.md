# Вариант `config-hrm.kbd`

Отдельный экспериментальный конфиг. Исходный `config.kbd` не изменён.
2026-09-24 вариант запущен через временный systemd drop-in
`/run/user/1000/systemd/user/kanata.service.d/90-hrm-trial.conf`.
После перезагрузки сервис снова использует исходный конфиг.
Комфорт при реальной печати ещё требует проверки.
Основная идея: оставить модификаторы на домашнем ряду, убрать
дополнительные удержания с букв и разделить ввод текста и команды.

## Основной слой

Пробел остаётся обычным во всех слоях: без tap/hold и без дополнительной
задержки от собственного переназначения. Политика и тайминги HRM сохранены:
Alt/Super/Ctrl — 400 мс, Shift — 300 мс, `tap-hold-opposite-hand-release`.

| Клавиши   | При удержании |
| --------- | ------------- |
| `a` / `;` | Alt           |
| `s` / `l` | Super         |
| `d` / `k` | Ctrl          |
| `f` / `j` | Shift         |

| Клавиша    | Коротко     | Удержание                            |
| ---------- | ----------- | ------------------------------------ |
| Caps       | Esc         | Навигация                            |
| Tab        | Tab         | Символы                              |
| Левый Alt  | Backspace   | Приложения                           |
| Правый Alt | Смена языка | Числа, команды и выбор подслоя       |
| Enter      | Enter       | Через 600 мс — обычный режим без HRM |

Вход в слои — после 200 мс удержания. Короткие действия Caps/Tab/Alt
выдаются при отпускании; это сознательный компромисс, которого нет у пробела.
У Alt прежний порог удержания сохранён.

Три буквенных аккорда основного слоя:

- `d+f`: коротко Esc, удержание Ctrl+Shift.
- `j+k`: коротко Enter, удержание Ctrl+Shift.
- `s+f`: Super+Shift.

Окно аккордов — прежние 35 мс, минимальный простой — 80 мс.
Оба физических Shift вместе возвращают основной слой. В обычном режиме
буквенные аккорды отключены, удержание Enter также возвращает основной слой.
Физический Backspace работает; Ctrl+W по-прежнему выдаёт Backspace.

## Навигация: удерживать Caps

Caps удерживает левый мизинец, все навигационные команды находятся справа.
Для Ctrl и Shift используются большие пальцы, без удержания левых букв.

| Клавиши    | Действие                                   |
| ---------- | ------------------------------------------ |
| `h j k l`  | Влево, вниз, вверх, вправо                 |
| `n m`      | Ctrl+Left / Ctrl+Right — переход по словам |
| `y ;`      | Home / End; также доступны на `[` / `]`    |
| `u i`      | Предыдущая / следующая вкладка             |
| `o p`      | Alt+Left / Alt+Right — назад / вперёд      |
| `'`        | Delete                                     |
| `/`        | Tab                                        |
| Левый Alt  | Непосредственный Ctrl                      |
| Правый Alt | Непосредственный Shift                     |

Для выделения: Caps + правый Alt + стрелки. Для выделения по словам:
Caps + правый Alt + N/M. Переключение вкладок теперь всегда на U/I;
прежние Alt+J/K не нужны. Физические модификаторы, кроме переназначенных
Alt, остаются доступны. Enter не используется для входа в частые слои.

## Символы: вход удерживает противоположная рука

**Удерживать Tab слева → вводить частые символы справа:**

```text
Физически: y u i o p
Символы:   ` [ ] + —

Физически: h j k l ; '
Символы:   - ( ) @ : "

Физически: n m , . /
Символы:   _ = < > ?
```

`p` в этом слое ничего не делает, как и раньше.

**Удерживать правый Alt, затем H → вводить остальные символы слева:**

```text
Физически: q w e r t
Символы:   ~ { } & \

Физически: a s d f g
Символы:   ! # * | %

Физически: z x c v b
Символы:   ^ $ ; ' /
```

Правый большой палец держит Alt, указательный — H; левая рука свободна.
Этот дополнительный селектор позволяет сохранить прямой доступ к числам
под правым Alt и оставить пробел обычным. Это компромисс: для второго
набора символов нужны две удерживаемые клавиши вместо одной.

Оба слоя переключают xkb на US и восстанавливают язык при отпускании
своего входа: Tab для правых символов, H для левых. Слои не входят друг
в друга. В левом наборе отпускание Alt раньше H не завершает символы:
слой и US остаются активны до отпускания H.

## Числа и команды: удерживать правый Alt

```text
q w e r t → 6 7 8 9 0
a s d f g → 1 2 3 4 5
```

| Клавиши        | Действие                                       |
| -------------- | ---------------------------------------------- |
| `z x`          | Предыдущий рабочий стол / предыдущее окно      |
| `c v`          | Копировать / вставить                          |
| `b`            | Последняя сессия kitty                         |
| `y u`          | Скриншот монитора / выделенной области в буфер |
| `i o m n`      | `+ = - _`                                      |
| `h` удерживать | Левые символы, см. выше                        |
| `j` удерживать | Shift+цифра на тех же левых клавишах           |
| `k` удерживать | Super+цифра — перейти на рабочий стол          |
| `l` удерживать | Super+Shift+цифра — перенести окно             |

Сначала активировать слой правым Alt, затем нажимать его селектор.
Селекторы срабатывают сразу. Обычно отпускать селектор перед правым Alt.
Числа, редактирование и предыдущие окно/стол/сессия вводятся свободной
левой рукой. Скриншоты, арифметика и селекторы доступны правым пальцам,
пока большой палец держит Alt.

Прежний вход в рабочие столы через левый Alt+L также сохранён.
Shift+цифры, как в исходнике, зависят от текущей раскладки xkb;
для фиксированной пунктуации использовать слои символов.

## Приложения: удерживать левый Alt

Привязки внутри `apps` сохранены:

| Клавиши        | Действие                                                               |
| -------------- | ---------------------------------------------------------------------- |
| `a b c e u`    | Приложения, закладки, сессии kitty, проекты, YouTube                   |
| `q`            | Закрыть окно через прежний `close-window.sh`                           |
| `r t`          | Сессии daily note / todos                                              |
| `o w h d g`    | Сессии Obsidian / downloads / home / dotfiles / GitHub                 |
| `y`            | YouTube Watch Later                                                    |
| `s` коротко    | Браузер                                                                |
| `s` удерживать | Сайты: `e` Gmail, `f` Perplexity, `g` ChatGPT, `d` Claude, `r` Reverso |
| `z`            | Sioyek                                                                 |
| `.`            | Emoji в буфер                                                          |
| `l` удерживать | Рабочие столы на левых буквенных клавишах                              |
| Caps           | Обычный Caps Lock                                                      |

Системные аккорды действуют только внутри `apps`, на прежних местах:

| Аккорд                | Действие               |
| --------------------- | ---------------------- |
| `w+e`                 | Обзор системы          |
| `e+r` / `r+t`         | AI limits / обновления |
| `d+f`                 | Уведомления            |
| `x+c` / `c+v`         | Календарь / питание    |
| `y+u`                 | Панель аудио           |
| `u+i` / `i+o` / `o+p` | Тише / громче / mute   |
| `h+j` / `l+;`         | Wi-Fi / Bluetooth      |
| `j+k` / `k+l`         | Яркость ниже / выше    |

## Что переехало относительно исходного config.kbd

| Раньше                                          | Теперь                                          |
| ----------------------------------------------- | ----------------------------------------------- |
| Удержание `w` или Caps → навигация              | Удержание Caps, команды справа                  |
| Удержание `c/v` → copy/paste                    | Правый Alt+C/V; обычные Ctrl+C/V также доступны |
| Удержание `z/x/b` → предыдущий стол/окно/сессия | Правый Alt+Z/X/B                                |
| Навигация+`s`, tap/hold → скриншоты             | Правый Alt+Y/U                                  |
| `s+d` → частые символы                          | Tab + правая клавиша                            |
| `s+d+f` → второй набор символов                 | Правый Alt+H + левая клавиша                    |
| `k+l` / `j+k+l` → числа / Shift+числа           | Правый Alt / правый Alt+J                       |
| Удержание `m` → рабочие столы                   | Правый Alt+K; левый Alt+L сохранён              |
| Удержание `n` или `j+l` → перенос окна          | Правый Alt+L                                    |
| `w+e` → Tab                                     | Физический Tab или Caps+/                       |
| Удержание любого Alt → приложения               | Только левый Alt                                |
| Арифметика на `z/x/c/v` числового слоя          | Правый Alt+I/O/M/N                              |

Вспомогательные слои используют обычные клавиши для незаданных позиций,
без наследования HRM из основного слоя. Удалены неиспользуемый `sw-lalt`
и прежние шаблоны/входы, заменённые новой схемой. Два alias для Alt+J/K
удалены: переключение вкладок осталось на U/I навигационного слоя. Все 35 различных внешних
команд и оба макроса сохранены; повтор команды уведомления о базовом слое
объединён в один alias. Новые маршруты не проверялись на физической клавиатуре.

Проверка синтаксиса без активации:

```sh
/usr/bin/kanata_cmd_allowed --check --cfg config-hrm.kbd
```
